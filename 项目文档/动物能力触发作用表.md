# 动物能力触发、作用范围与效果类型表

说明：
- `triggerType` 是“什么时候触发”
- `impactType` 是“打到谁 / 影响哪一片”
- `effectType` 是“具体做什么”
- 下面的“为什么这么设”是结合当前代码实现和配置意图做的说明，属于设计解读

## 触发与作用范围对照说明

### triggerType 常见语义
- `SettlementPrepare`：白天结算前，当前项目里是最主力的日常能力触发时机
- `Passive`：不靠普通结算扫表，而是由保护/容器体系常驻参与
- `Moved`：自己移动后触发
- `AdjacentAnimalMoved`：邻居移动后触发
- `AnimalRemoved`：自己被移除后触发
- `AdjacentAnimalRemoved`：邻居被移除后触发
- `AnimalPreyed`：某个动物被捕食后触发
- `AnimalPreyedSelf`：自己被捕食时触发
- `GlobalAnimalPreyed`：全场任意捕食事件都能监听到

### impactType 常见语义
- `Self`：只影响自己
- `Adjacent`：影响相邻格
- `Global` / `Field` / `All`：影响整场
- `Row`：影响同一行
- `Up`：只看上方
- `Right`：只看右侧
- `Left` / `Down`：当前数据里没用到，但解析器已支持

### 为什么大部分都是 `SettlementPrepare`
当前项目的动物能力设计，核心是“围绕日结前的站位和邻域关系做收益”，所以把多数主动能力放在 `SettlementPrepare` 上，能统一在一天结算前做一次地图扫描，避免把逻辑拆散到移动、出售、捕食等多个时机里。

### 为什么 `Passive` 很少
`Passive` 更适合保护类、容器类、规则挂载类能力。它们不是“某一刻触发一次”，而是“在相关事件发生时持续参与判定”，所以数量少、但职责很稳定。
