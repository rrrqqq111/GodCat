# 双家族动物支持更新目录

## 更新目的

本次更新为动物配置表增加“第二家族”字段。动物可以同时属于主家族和第二家族，并且会被对应的图鉴分类、家族筛选、随机生成、能力目标判断、捕食/保护规则识别到。

示例：

- 主家族 `Bird`
- 第二家族 `Carnivora`

该动物会同时被鸟类筛选和食肉类筛选检测到。

## 文件改动说明

`AnimalData.cs`

- 新增 `secondaryFamily` 字段，Unity 检查器中显示为“第二家族”。
- 新增 `SecondaryFamily` 只读属性。
- 新增 `HasFamily(string familyId)` 方法。
- 主家族或第二家族任意一个匹配时，`HasFamily` 都会返回 `true`。

`RanchContentCatalog.cs`

- 自动按家族生成动物候选池时，改为使用 `HasFamily`。
- 双家族动物会进入两个家族对应的候选池。

`RanchAnimalSpawnService.cs`

- `TrySpawnRandomFromFamily` 支持从主家族或第二家族中筛选。
- `TrySpawnRandomOutsideFamilyAt` 会排除主家族或第二家族命中的动物。

`AnimalBookIconListController.cs`

- 图鉴分类筛选改为使用 `HasFamily`。
- 双家族动物会出现在两个对应家族的图鉴分类中。

`AbilityTargetResolver.cs`

- 能力通用目标筛选中的 `targetFamily` 改为识别第二家族。

`PreyTargetRule.cs`

- 捕食目标规则的目标家族和排除家族都会识别第二家族。

`ProtectionRule.cs`

- 保护者家族、被保护对象家族、捕食者家族判断都会识别第二家族。

具体能力脚本：

- `CoyoteAbilityEffect.cs`
- `HyenaAbilityEffect.cs`
- `OstrichAbilityEffect.cs`
- `PeacockAbilityEffect.cs`
- `MuskOxAbilityEffect.cs`
- `HippoAbilityEffect.cs`

这些脚本中原本直接比较 `animal.Data.Family` 的地方，已改为 `animal.Data.HasFamily(...)`。

## 学生手动替换步骤

1. 关闭 Unity，避免脚本正在被编辑器占用。
2. 按上方“需要替换的文件”列表，将文件复制到项目相同路径。
3. 如果系统提示是否覆盖，选择覆盖。
4. 重新打开 Unity，等待脚本重新编译。
5. 打开任意动物配置表，在检查器中找到“第二家族”字段。
6. 给需要双家族的动物填写第二家族，例如 `Carnivora`、`Bird`、`Hoofed`。

## 配置规则

- `family` 仍然作为主家族使用。
- `secondaryFamily` 是第二家族，可以留空。
- 资源文件不需要复制两份。
- 动物资源仍然建议放在主家族文件夹下。

例如：

```text
Assets/Game/Data/Animals/Bird/owl.asset
```

如果猫头鹰同时属于 `Bird` 和 `Carnivora`：

```text
family = Bird
secondaryFamily = Carnivora
```

## 验证方式

替换后可以用以下方式检查：

1. 找一个动物配置，填写第二家族。
2. 打开图鉴，切换到主家族分类，应能看到该动物。
3. 切换到第二家族分类，也应能看到该动物。
4. 如果有按家族触发的能力或捕食规则，该动物应能被对应家族规则检测到。

## 注意事项

- 第二家族字段为空时，动物行为与旧版本一致。
- 不要为了双家族复制两份动物配置表，否则数值和能力容易不同步。
- 本次只支持一个第二家族。如果以后需要三个以上家族，建议再把字段升级为家族列表。
