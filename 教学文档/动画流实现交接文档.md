# 猫神牧场动画流实现交接文档

> 面向新的 Codex/vibecoding 对话。目标是让新对话快速理解当前 Unity 项目架构，并接手实现“点击下一天后的整套回合动画流”。

## 1. 本次任务目标

玩家界面只保留“下一天”按钮。点击后不再立即无演出结算，而是播放一条完整的回合演出流水线：

1. 锁定输入。
2. 场上动物消失，同时天黑，播放半透明黑幕转场。
3. 播放牧场门关闭和打开动画。
4. 被选中上场/当前要上场的动物按顺序从牧场门位置出现，平移到自己的地块。
5. 按地图扫描顺序触发动物能力。
6. 触发能力的动物跳跃一下，播放对应音效，头顶弹出金币/数值，金币飞入左上角 HUD 后消失。
7. 能力全部演出后，统计基础属性收益，也播放金币/数值飞入 HUD 的表现。
8. 更新 HUD，解锁输入，进入下一天可操作状态。

核心要求：动画层不要直接写死结算逻辑。推荐让逻辑层产出“演出事件”，动画层按顺序消费事件。

## 2. 当前项目核心架构

### RanchManager 是门面

入口文件：

- `Assets/Game/Scripts/Ranch/RanchManager.cs`

职责：

- 场景初始化。
- 创建各个 service。
- 向 UI、能力、道具、测试脚本暴露统一 API。
- 透传事件和状态刷新。

常见入口：

- `RanchManager.NextDay()`：当前由 HUD 下一天按钮调用。
- `RanchManager.AddMoney(...)`
- `RanchManager.TryTriggerAnimalAbilityWithResult(...)`
- `RanchManager.TryAddAnimalAtEmptyCell(...)`
- `RanchManager.TryMoveAnimal(...)`
- `RanchManager.StateChanged`

注意：不要把复杂动画流程全部塞回 `RanchManager`。更推荐新增一个 Flow/Presentation 层，由 `RanchManager` 持有或被 UI 调用。

### 回合推进在 RanchTurnService

入口文件：

- `Assets/Game/Scripts/Ranch/RanchTurnService.cs`

当前流程：

- `NextDay()`
  - 如果当前是 `DayTransition`，进入下一天。
  - 如果当前是 `OfferSelection`，直接返回。
  - 否则调用 `RanchSettlementService.ResolveDailySettlement(...)` 做结算。
  - 非测试模式下刷新候选动物。
  - 切换到 `OfferSelection` 或 `DayTransition`。

动画流要改造这里附近，但不要直接把所有协程写进 `RanchTurnService`。建议新增：

- `RanchTurnFlowController`
- 或 `RanchPresentationFlow`

由它串联动画和逻辑。

### 结算和能力在 RanchSettlementService

入口文件：

- `Assets/Game/Scripts/Ranch/RanchSettlementService.cs`

关键方法：

- `ResolveDailySettlement(RanchMap ranchMap)`
- `TryTriggerAnimalAbility(Animal animal)`
- `TryTriggerAnimalAbility(Animal animal, string triggerType)`

当前结算顺序：

1. `SettlementPrepare`
2. `DayStart`
3. `DayEnd`
4. 遍历地图动物，消耗地块物体，计算基础收益。
5. 一次性加总金币。
6. 生成文字结算报告。

当前问题：

- `ResolveDailySettlement` 直接改钱和报告，不返回详细演出事件。
- 动画流需要知道“哪个动物触发了能力”“获得了多少金币”“哪个动物产生了基础收益”。

建议改造方向：

- 新增结算结果模型，例如 `RanchSettlementPresentationResult`。
- 让结算服务可以返回能力事件和基础收益事件。
- 第一版可保留旧 `ResolveDailySettlement`，新增一个面向演出的 `ResolveDailySettlementWithEvents(...)`，降低风险。

### 能力结果已有基础结构

入口文件：

- `Assets/Game/Scripts/Abilities/AbilityExecutionResult.cs`

当前字段：

- `Success`
- `AbilityId`
- `TriggerType`
- `TargetCount`
- `MoneyDelta`

可作为能力演出事件的基础，但还缺：

- `Animal Actor`
- `Vector2Int SourceCoords`
- `string SoundId`
- `string VfxId`
- `int BaseMoneyDelta`

建议不要直接无限扩展 `AbilityExecutionResult`，可以新增 presentation event 类型包装它。

## 3. 地图、动物显示、HUD

### RanchMap 和 MapCell

入口文件：

- `Assets/Game/Scripts/Ranch/RanchMap.cs`
- `Assets/Game/Scripts/Ranch/MapCell.cs`

`RanchMap` 负责格子集合、邻居、扫描顺序、放置/移动/交换/移除动物。

重要方法：

- `GetCellsInScanOrder()`
- `GetNeighbors(Vector2Int coords)`
- `TryGetCell(Vector2Int coords, out MapCell cell)`
- `TryPlaceAnimal(...)`
- `TryMoveAnimal(...)`
- `TrySwapAnimals(...)`

`MapCell` 持有：

- `Animal Animal`
- `AnimalView animalView`
- `MapCellObjectRuntime MapObject`

`MapCell.RefreshView()` 当前是私有方法，会在放置/移除动物、换地形贴图时刷新视图。

动画流可能需要：

- 暴露 `AnimalView` 读取接口，例如 `public AnimalView AnimalView => animalView;`
- 或在 `RanchMap`/`MapCell` 中新增查询某动物对应 View 的方法。

### AnimalView

入口文件：

- `Assets/Game/Scripts/Ranch/AnimalView.cs`

当前已有：

- `Refresh(Animal animal, Sprite fallbackSprite, Sprite tileSprite, int sortingOrder)`
- `PlayAbilityFeedback()`
- `PlayMoveFeedback()`

`PlayAbilityFeedback()` 和 `PlayMoveFeedback()` 当前是空方法，正适合接动画。

建议扩展：

- `IEnumerator PlayEnterFrom(Vector3 worldStart, Vector3 worldEnd, float duration)`
- `IEnumerator PlayAbilityJump(float height, float duration)`
- `void SetVisible(bool visible)` 或 `Fade(...)`

不要让 `AnimalView` 自己决定回合流程，它只负责单个动物表现。

### RanchHUD

入口文件：

- `Assets/Game/Scripts/UI/RanchHUD.cs`

当前职责：

- 显示天数、金币、罐头、选择信息、结算报告。
- 绑定 `nextDayButton`。

动画流可能需要：

- 暴露左上角金币目标位置，例如 `Transform MoneyTarget`。
- 在动画期间禁用按钮。
- 支持仅显示“下一天”文案。
- 可新增 `SetNextDayInteractable(bool interactable)`。

注意：当前文件里部分中文文本在 PowerShell 中显示为乱码，这是控制台编码问题，不一定代表 Unity 中显示异常。

## 5. 建议新增的动画流脚本

推荐新增目录：

- `Assets/Game/Scripts/Presentation`
- 或 `Assets/Game/Scripts/Ranch/Presentation`

推荐脚本：

### RanchTurnFlowController

职责：

- 响应“下一天”。
- 锁定输入。
- 调用演出 director。
- 调用结算逻辑并拿到演出事件。
- 逐条播放能力、收益、金币飞入 HUD。
- 最后推进到下一天状态。

建议接口：

```csharp
public class RanchTurnFlowController : MonoBehaviour
{
    public void Initialize(RanchManager manager, RanchAnimationDirector director);
    public void PlayNextDayFlow();
}
```

第一版可用协程：

```csharp
private IEnumerator NextDayFlowRoutine()
{
    inputLocked = true;
    yield return director.PlayDayTransition();
    yield return director.PlayGateSequence();
    yield return director.PlayAnimalEnterSequence(...);
    var result = settlementService.ResolveDailySettlementWithEvents(...);
    yield return director.PlayAbilityEvents(result.AbilityEvents);
    yield return director.PlayIncomeEvents(result.IncomeEvents);
    inputLocked = false;
}
```

### RanchAnimationDirector

职责：

- 只管表现，不算游戏逻辑。
- 播放黑幕、牧场门、动物入场、动物跳跃、飘字、金币飞 HUD、音效。

建议字段：

- `CanvasGroup fadeOverlay`
- `Transform ranchGate`
- `Transform animalEnterPoint`
- `Transform moneyHudTarget`
- `FloatingRewardPresenter rewardPresenter`
- `RanchAudioCueService audioCueService`

建议接口：

```csharp
IEnumerator PlayDayTransition();
IEnumerator PlayGateSequence();
IEnumerator PlayAnimalEnter(AnimalView view, Vector3 from, Vector3 to);
IEnumerator PlayAbilityEvent(AbilityPresentationEvent evt);
IEnumerator PlayIncomeEvent(IncomePresentationEvent evt);
```

### FloatingRewardPresenter

职责：

- 在动物头顶弹出金币和数值。
- 金币飞向 HUD。
- 到达后销毁。

建议接口：

```csharp
IEnumerator PlayMoneyFly(Vector3 worldStart, int amount);
IEnumerator PlayPopup(Vector3 worldStart, string text);
```

### RanchAudioCueService

职责：

- 根据 `soundId` 播放音效。
- 不要让能力脚本直接播放 AudioSource。

建议接口：

```csharp
void Play(string soundId);
```

## 6. 建议新增的演出事件模型

推荐新增：

- `AbilityPresentationEvent`
- `IncomePresentationEvent`
- `RanchSettlementPresentationResult`

示例：

```csharp
public readonly struct AbilityPresentationEvent
{
    public readonly Animal Actor;
    public readonly string AbilityId;
    public readonly string TriggerType;
    public readonly int MoneyDelta;
    public readonly int TargetCount;
    public readonly string SoundId;
}
```

```csharp
public readonly struct IncomePresentationEvent
{
    public readonly Animal Animal;
    public readonly int Amount;
}
```

```csharp
public sealed class RanchSettlementPresentationResult
{
    public List<AbilityPresentationEvent> AbilityEvents { get; } = new();
    public List<IncomePresentationEvent> IncomeEvents { get; } = new();
    public int TotalIncome { get; set; }
    public string Report { get; set; }
}
```

第一版可以只实现：

- 能力成功且 `MoneyDelta != 0` 时播放金币。
- 基础收益 `Amount != 0` 时播放金币。
- 没钱的能力也让动物跳一下，方便玩家看到“触发过”。

## 7. 推荐实现顺序

### 第一步：搭骨架

1. 新增 `RanchAnimationDirector`。
2. 新增黑幕 `CanvasGroup` 字段。
3. 新增牧场门和动物入场点字段。
4. 新增空实现协程，先用 `yield return new WaitForSeconds(...)` 串起来。

验收：点击下一天后，能看到黑幕和流程延迟，按钮期间不可重复点击。

### 第二步：接动物入场

1. 给 `MapCell` 暴露 `AnimalView`。
2. 给 `AnimalView` 增加显示/隐藏、移动协程。
3. 从 `RanchMap.GetCellsInScanOrder()` 拿动物顺序。
4. 动物从牧场门位置移动到格子位置。

验收：当前场上动物按顺序从门口移动到自己的格子。

### 第三步：结算结果事件化

1. 新增 `RanchSettlementPresentationResult`。
2. 新增 `ResolveDailySettlementWithEvents(...)`。
3. 暂时保留旧 `ResolveDailySettlement(...)`。
4. 在能力执行后记录 `AbilityPresentationEvent`。
5. 在基础收益阶段记录 `IncomePresentationEvent`。

验收：不播放动画时，事件数量和结算报告能对得上。

### 第四步：播放能力和收益

1. 能力事件：动物跳跃，播放音效，金币/数值飞 HUD。
2. 收益事件：动物头顶弹基础收益，金币飞 HUD。
3. HUD 最终刷新状态。

验收：能力和基础收益按扫描顺序逐个播放。

### 第五步：打磨

1. 增加跳过动画。
2. 增加倍速。
3. 给不同 `AbilityId` 配不同 `soundId`。
4. 增加对象池，避免频繁 Instantiate/Destroy。

## 8. 输入锁定和状态建议

当前状态 enum：

- `Assets/Game/Scripts/Ranch/RanchPhase.cs`
- `Playing`
- `OfferSelection`
- `DayTransition`
- `TestMode`

建议新增或复用一个动画中状态：

- 可新增 `Animating`
- 或在 `RanchTurnFlowController` 内部维护 `bool IsAnimating`

第一版更稳妥：

- 先在 flow controller 内部用 `isAnimating`。
- HUD 按钮点击时如果 `isAnimating`，直接 return。
- 地块点击、道具使用等后续再统一接输入锁。

## 9. 需要特别小心的点

1. 不要让动画决定游戏结果。游戏结果仍由 service 计算。
2. 不要在能力脚本里直接写动画或音效。能力脚本只做逻辑。
3. 不要一次性重写 `RanchSettlementService`。先新增返回事件的方法，稳定后再替换旧入口。
4. 现有能力可能会移动、生成、删除、变形动物。动画事件里保存 `Animal` 引用时，要考虑动物可能被移除。必要时保存 `Coords`、`DisplayName`、`Icon` 等快照。
5. 金币飞入 HUD 的数值更新方式要统一：可以先逻辑立即加钱，动画只表现；也可以动画结束再刷新 HUD。第一版建议逻辑立即结算，动画只表现，风险更低。
6. 场景里需要手动挂引用：黑幕、牧场门、入场点、HUD 金币目标点。

## 10. 本任务第一版验收标准

完成后应满足：

1. 点击下一天后按钮不能重复触发。
2. 黑幕转场可以播放。
3. 牧场门动画有占位表现。
4. 动物能按 `RanchMap.GetCellsInScanOrder()` 顺序从门口移动到目标格。
5. 能力触发按原结算顺序播放动物跳跃。
6. 有金币收益的能力和基础收益能显示数值，并飞向 HUD。
7. 原有结算数值不变。
8. `dotnet build Assembly-CSharp-Editor.csproj -nologo` 通过。
