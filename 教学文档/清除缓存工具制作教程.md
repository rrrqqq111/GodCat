# 清除缓存工具制作教程

## 本节目标

本节课要制作一个 Unity 编辑器工具，用来一键清除本项目的本地缓存。

这里的“缓存”主要指 `PlayerPrefs` 中保存的数据，例如：

- 家族选择下标：`SelectedOptionIndices`
- 家族选择结果：`SelectedAnimalFamilies`
- UI 音量：`UI_VOLUME`
- BGM 音量：`BGM_VOLUME`
- 分辨率选项：`RESOLUTION_OPTION`
- 屏幕模式选项：`SCREEN_MODE_OPTION`
- 鼠标皮肤开关：`CURSOR_SKIN_ENABLED`

完成后，Unity 顶部菜单会出现：

```text
Tools/Game/Clear User Cache
```

点击后会弹出确认框。确认后，会清除当前项目的全部 `PlayerPrefs`。

## 为什么需要这个工具

在调试开始界面、家族选择、设置面板时，经常会遇到旧数据影响测试的问题。

例如：

- 上一次选择过 `Hoofed,Bird,Carnivora`，下一次测试时游戏仍然读取旧选择。
- 音量、分辨率、屏幕模式被保存后，不方便恢复默认。
- 学生之间测试结果不一致，其实是本地缓存不同。

用清除缓存工具可以快速回到“第一次打开游戏”的状态。

## 涉及文件

本节只需要新增 1 个脚本：

```text
Assets/Game/Scripts/Editor/UserCacheTools.cs
```

注意：必须放在名为 `Editor` 的文件夹下。因为这个脚本使用了 `UnityEditor`，只能在编辑器中运行，不能进入游戏打包。

如果项目中还没有这个文件夹，就创建：

```text
Assets/Game/Scripts/Editor
```

## 第一步：创建 Editor 文件夹

在 Unity Project 窗口中找到：

```text
Assets/Game/Scripts
```

如果里面没有 `Editor` 文件夹：

1. 右键 `Scripts`
2. 选择 `Create > Folder`
3. 命名为 `Editor`

最终路径应为：

```text
Assets/Game/Scripts/Editor
```

## 第二步：创建 UserCacheTools 脚本

在 `Editor` 文件夹中：

1. 右键空白区域
2. 选择 `Create > C# Script`
3. 命名为：

```text
UserCacheTools
```

确认文件路径是：

```text
Assets/Game/Scripts/Editor/UserCacheTools.cs
```

## 第三步：填写脚本代码

打开：

```text
Assets/Game/Scripts/Editor/UserCacheTools.cs
```

删除默认生成的 `MonoBehaviour` 代码，改成下面完整代码：

```csharp
using UnityEditor;
using UnityEngine;

namespace Game.EditorTools
{
    public static class UserCacheTools
    {
        [MenuItem("Tools/Game/Clear User Cache")]
        public static void ClearUserCache()
        {
            var confirmed = EditorUtility.DisplayDialog(
                "Clear User Cache",
                "This will clear all PlayerPrefs for this project, including selected families, settings, volume, resolution, and other local user cache data.",
                "Clear",
                "Cancel");

            if (!confirmed)
            {
                return;
            }

            PlayerPrefs.DeleteAll();
            PlayerPrefs.Save();
            Debug.Log("[UserCacheTools] Cleared all PlayerPrefs user cache data.");
        }
    }
}
```

## 代码说明

`using UnityEditor;`

- 允许我们使用 Unity 编辑器专用 API。
- 例如 `MenuItem` 和 `EditorUtility.DisplayDialog`。
- 因为用了 `UnityEditor`，所以脚本必须放在 `Editor` 文件夹中。

`[MenuItem("Tools/Game/Clear User Cache")]`

- 这行会在 Unity 顶部菜单创建一个按钮。
- 菜单路径是：

```text
Tools > Game > Clear User Cache
```

`EditorUtility.DisplayDialog(...)`

- 点击菜单后弹出确认框。
- 防止误点后直接清掉缓存。

`PlayerPrefs.DeleteAll();`

- 清除当前项目保存的全部 `PlayerPrefs`。
- 包括家族选择、设置项、音量、分辨率等。

`PlayerPrefs.Save();`

- 立刻把清除结果写入本地。

`Debug.Log(...)`

- 在 Console 中打印提示，方便确认工具已经执行。

## 第四步：在 Unity 中使用工具

保存脚本后，回到 Unity。

等待右下角或底部状态栏编译完成。

编译完成后，查看 Unity 顶部菜单：

```text
Tools
```

里面应该出现：

```text
Game > Clear User Cache
```

点击：

```text
Tools > Game > Clear User Cache
```

会弹出确认框。

点击 `Clear`，Console 中应该出现：

```text
[UserCacheTools] Cleared all PlayerPrefs user cache data.
```

点击 `Cancel`，不会清除任何内容。

## 第五步：验证清除是否成功

### 方法一：验证家族选择缓存

1. 进入 Play 模式。
2. 在游戏开始界面选择家族并确认。
3. 退出 Play 模式。
4. 执行：

```text
Tools > Game > Clear User Cache
```

5. 再次进入 Play 模式。

预期结果：

- 家族选择不会再读取上一次的旧选择。
- `SelectedAnimalFamilies` 被清空。
- `SelectedOptionIndices` 被清空。

### 方法二：临时打印 PlayerPrefs

可以在任意测试脚本中临时加入：

```csharp
Debug.Log("SelectedAnimalFamilies = " + PlayerPrefs.GetString("SelectedAnimalFamilies", "<empty>"));
Debug.Log("SelectedOptionIndices = " + PlayerPrefs.GetString("SelectedOptionIndices", "<empty>"));
```

清除缓存前，可能输出：

```text
SelectedAnimalFamilies = Hoofed,Bird,Carnivora
SelectedOptionIndices = 0,1,2
```

清除缓存后，应输出：

```text
SelectedAnimalFamilies = <empty>
SelectedOptionIndices = <empty>
```

验证完成后，删除临时 `Debug.Log`。

### 方法三：验证设置缓存

1. 打开游戏设置面板。
2. 修改 UI 音量、BGM 音量、分辨率或屏幕模式。
3. 执行清除缓存工具。
4. 重新进入 Play 模式。

预期结果：

- 音量恢复默认值。
- 分辨率和屏幕模式恢复默认值。
- 鼠标皮肤设置也恢复默认。

## 常见问题

### 顶部菜单没有出现 Tools/Game/Clear User Cache

检查：

- 脚本是否放在 `Assets/Game/Scripts/Editor/UserCacheTools.cs`。
- 文件夹名字是否准确叫 `Editor`。
- 脚本是否编译报错。
- 类是否是 `public static class UserCacheTools`。
- 方法是否有 `[MenuItem("Tools/Game/Clear User Cache")]`。

### 报错：The type or namespace name 'UnityEditor' could not be found

原因：

- 脚本没有放进 `Editor` 文件夹。

解决：

- 确认路径是：

```text
Assets/Game/Scripts/Editor/UserCacheTools.cs
```

### 点了菜单但旧选择还在

检查：

- 是否点击了确认框中的 `Clear`，而不是 `Cancel`。
- Console 是否出现：

```text
[UserCacheTools] Cleared all PlayerPrefs user cache data.
```

- 是否有其他脚本在 Play 模式启动时又重新写入了缓存。

### DeleteAll 会不会删除项目资源

不会。

`PlayerPrefs.DeleteAll()` 只删除本机本项目的用户偏好数据，不会删除：

- `.cs` 脚本
- `.unity` 场景
- `.asset` 动物配置
- 图片资源
- Prefab

它影响的是玩家本地缓存，不是项目文件。

## 完成标准

完成后应满足：

1. 项目中存在 `Assets/Game/Scripts/Editor/UserCacheTools.cs`。
2. Unity 顶部菜单出现 `Tools > Game > Clear User Cache`。
3. 点击菜单后会弹出确认框。
4. 点击 `Clear` 后 Console 打印清除成功日志。
5. 家族选择、音量、分辨率等 `PlayerPrefs` 缓存被清空。
6. 重新进入 Play 模式时，游戏表现为未保存过本地设置的状态。
