# 阶段胜负判断系统实现教程

本教程基于上一次提交版本 `a3ebaa9 保证每个家族都有动物了` 编写。目标是在牧场游戏中加入“阶段结束后按金币目标判断”的基础胜负流程，并在 UI 中显示当前阶段和目标金币。

本次只涉及下面 4 个脚本：

- `Assets/Game/Scripts/Ranch/RanchWinLoseController.cs`：新建脚本，专门管理阶段目标、阶段结束面板和按钮事件。
- `Assets/Game/Scripts/Ranch/RanchTurnService.cs`：在每天结算完成后接入阶段结束判断。
- `Assets/Game/Scripts/Ranch/RanchManager.cs`：只做薄薄的中转，不把胜负规则塞进这里。
- `Assets/Game/Scripts/UI/游戏场景/RanchUIController.cs`：显示当前阶段数和当前阶段金币目标。

注意：老师当前工程里的 `RanchManager.cs` 可能还有其他改动，例如 `SelectedAnimalFamiliesPlayerPrefsKey`、`ApplySelectedAnimalFamilies()`、`ParseSelectedAnimalFamilies()`。这些和本教程无关，学生不要添加。

## 功能目标

实现后效果如下：

1. 游戏分阶段进行，默认只有 1 个阶段。
2. 第 1 阶段默认持续 6 天，目标金币为 25。
3. 判断时机是阶段最后一天结算完成后。例如第 1 阶段为 6 天，就在第 6 天结算完后判断。
4. 判断依据是玩家当前总金币余额 `Money`。
5. 阶段结束时一定弹出阶段结束面板，不管是否达标。
6. 面板中有两个按钮：
   - 放弃按钮：返回 `GameStartSence`。
   - 支付/继续按钮：进入下一阶段。
7. UI 上显示当前阶段数和当前阶段目标金币。

## 一、新建 RanchWinLoseController.cs

在 Unity Project 面板中找到：

`Assets/Game/Scripts/Ranch`

右键新建 C# Script，命名为：

`RanchWinLoseController`

把脚本内容替换为：

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.SceneManagement;
using UnityEngine.Serialization;
using UnityEngine.UI;

namespace NekogamiRanch.Ranch
{
    public class RanchWinLoseController : MonoBehaviour
    {
        [SerializeField] private List<RanchStageGoal> stageGoals = new List<RanchStageGoal>
        {
            new RanchStageGoal()
        };
        [SerializeField, Min(0)] private int currentStageIndex;
        [FormerlySerializedAs("failurePanel")]
        [SerializeField] private GameObject stageEndPanel;
        [SerializeField] private Button payButton;
        [SerializeField] private string giveUpSceneName = "GameStartSence";

        private RanchManager manager;

        public int CurrentStageIndex => currentStageIndex;
        public int CurrentStageNumber => currentStageIndex + 1;
        public int CurrentStageRequiredTotalMoney => GetCurrentGoal().RequiredTotalMoney;
        public bool HasResult => Result != RanchGameResult.Playing || IsStageEndPanelOpen;
        public bool IsStageEndPanelOpen { get; private set; }
        public RanchGameResult Result { get; private set; } = RanchGameResult.Playing;

        public void Initialize(RanchManager ranchManager)
        {
            manager = ranchManager;
        }

        private void Awake()
        {
            if (stageEndPanel != null)
            {
                stageEndPanel.SetActive(false);
            }

            SetPayButtonInteractable(false);
        }

        private void OnValidate()
        {
            if (stageGoals == null)
            {
                stageGoals = new List<RanchStageGoal>();
            }

            if (stageGoals.Count == 0)
            {
                stageGoals.Add(new RanchStageGoal());
            }

            currentStageIndex = Mathf.Clamp(currentStageIndex, 0, stageGoals.Count - 1);
        }

        public bool TryResolveStageEnd(int day, int totalMoney)
        {
            if (HasResult || !IsStageEndDay(day))
            {
                return false;
            }

            var goal = GetCurrentGoal();
            Result = totalMoney >= goal.RequiredTotalMoney ? RanchGameResult.StagePassed : RanchGameResult.Lost;
            ShowStageEndPanel();
            SetPayButtonInteractable(Result == RanchGameResult.StagePassed);
            return true;
        }

        public void ResetProgress()
        {
            currentStageIndex = 0;
            Result = RanchGameResult.Playing;
            IsStageEndPanelOpen = false;
            HideStageEndPanel();
            SetPayButtonInteractable(false);
        }

        public void GiveUpAndReturnToGameStart()
        {
            var sceneName = string.IsNullOrWhiteSpace(giveUpSceneName) ? "GameStartSence" : giveUpSceneName.Trim();

            if (global::SceneTransitionManager.Instance != null)
            {
                global::SceneTransitionManager.Instance.LoadSceneWithTransition(sceneName);
                return;
            }

            SceneManager.LoadScene(sceneName);
        }

        public void PayAndEnterNextStage()
        {
            if (!IsStageEndPanelOpen || Result != RanchGameResult.StagePassed)
            {
                return;
            }

            if (!TryAdvanceToNextStage())
            {
                return;
            }

            Result = RanchGameResult.Playing;
            IsStageEndPanelOpen = false;
            HideStageEndPanel();
            SetPayButtonInteractable(false);
            manager?.ContinueAfterStagePayment();
        }

        public void OnGiveUpButtonClicked()
        {
            GiveUpAndReturnToGameStart();
        }

        public void OnPayButtonClicked()
        {
            PayAndEnterNextStage();
        }

        private bool IsStageEndDay(int day)
        {
            var stageEndDay = 0;
            for (var i = 0; i <= currentStageIndex && i < stageGoals.Count; i++)
            {
                stageEndDay += stageGoals[i].DurationDays;
            }

            return day >= stageEndDay;
        }

        private RanchStageGoal GetCurrentGoal()
        {
            if (stageGoals == null || stageGoals.Count == 0)
            {
                return new RanchStageGoal();
            }

            currentStageIndex = Mathf.Clamp(currentStageIndex, 0, stageGoals.Count - 1);
            return stageGoals[currentStageIndex];
        }

        private void ShowStageEndPanel()
        {
            IsStageEndPanelOpen = true;
            if (stageEndPanel != null)
            {
                stageEndPanel.SetActive(true);
            }
        }

        private void HideStageEndPanel()
        {
            if (stageEndPanel != null)
            {
                stageEndPanel.SetActive(false);
            }
        }

        private bool TryAdvanceToNextStage()
        {
            if (stageGoals == null || stageGoals.Count == 0)
            {
                return false;
            }

            if (currentStageIndex >= stageGoals.Count - 1)
            {
                Debug.LogWarning("[RanchWinLoseController] Cannot pay to enter the next stage because no next stage is configured.");
                return false;
            }

            currentStageIndex++;
            return true;
        }

        private void SetPayButtonInteractable(bool interactable)
        {
            if (payButton != null)
            {
                payButton.interactable = interactable;
            }
        }
    }

    public enum RanchGameResult
    {
        Playing = 0,
        StagePassed = 1,
        Lost = 2
    }

    [Serializable]
    public class RanchStageGoal
    {
        [SerializeField, Min(1)] private int durationDays = 6;
        [SerializeField, Min(0)] private int requiredTotalMoney = 25;

        public int DurationDays => Mathf.Max(1, durationDays);
        public int RequiredTotalMoney => Mathf.Max(0, requiredTotalMoney);
    }
}
```

说明：

- `stageGoals` 是阶段列表，可以在 Inspector 里添加多个阶段。
- `durationDays` 是这个阶段持续几天。
- `requiredTotalMoney` 是阶段结束时要求玩家总金币至少达到多少。
- `stageEndPanel` 是阶段结束时弹出的面板。
- `payButton` 是支付/继续按钮，用来在未达标时禁用按钮。
- `OnGiveUpButtonClicked()` 和 `OnPayButtonClicked()` 是给按钮事件绑定的方法。

## 五、Unity 编辑器设置

### 1. 添加 RanchWinLoseController

打开游戏场景：

`Assets/Scenes/游戏界面.unity`

找到场景里的 `RanchManager` 对象。一般脚本 `RanchManager` 挂在哪个 GameObject 上，就选中哪个对象。

在 Inspector 中点击 `Add Component`，添加：

`RanchWinLoseController`

如果你想单独新建一个对象挂这个脚本也可以，但推荐先挂在 `RanchManager` 同一个对象上，最简单。

### 2. 配置阶段目标

在 `RanchWinLoseController` 组件中：

- `Stage Goals` 默认有 1 个元素。
- 第 1 个元素设置：
  - `Duration Days` = `6`
  - `Required Total Money` = `25`
- `Current Stage Index` 保持 `0`。

如果要测试多个阶段，可以把 `Stage Goals` 数组 Size 改成 2 或更多，例如：

- 第 1 阶段：6 天，25 金币。
- 第 2 阶段：5 天，50 金币。

注意：支付按钮进入下一阶段要求真的存在下一阶段。如果只有 1 个阶段，点击支付按钮不会进入下一阶段，并会在 Console 打印 warning。

### 3. 制作并绑定阶段结束面板

阶段结束面板要和游戏界面场景中已有的“账单界面”保持一致。这个界面模仿实际游戏中制作，跟随老师示范

`Canvas/账单界面`

它的结构大致是：

```text
账单界面
├─ 账单（挂有UIPanelFlyIn脚本，使其从上方飞入）
│  ├─ 猫神账单
│  └─ 上贡要求
├─ 支付按钮
│  └─ Text (TMP)
└─ 放弃按钮
   └─ Text (TMP)
```



两个按钮：

- `支付按钮` 和 `放弃按钮` 都是 UI Button。
- 每个按钮下面放一个 TMP 子文本，铺满按钮区域，用来显示按钮文字。

绑定到脚本：

1. 把整个根面板对象拖到 `RanchWinLoseController` 的 `Stage End Panel` 字段。
2. 把 `支付按钮` 拖到 `RanchWinLoseController` 的 `Pay Button` 字段。
3. 保持根面板默认 inactive。

这样金币不足时脚本才能自动禁用支付按钮，玩家只能点击放弃。

### 4. 绑定面板按钮

阶段结束面板中准备两个 Button：

3. 方法选择：

`RanchWinLoseController -> OnGiveUpButtonClicked()`

点击后会返回：

`GameStartSence`

#### 支付/继续按钮

选中按钮，在 `Button` 组件的 `On Click()` 中：

1. 点击 `+`。
2. 把挂有 `RanchWinLoseController` 的对象拖进去。
3. 方法选择：

`RanchWinLoseController -> OnPayButtonClicked()`

点击后会进入下一阶段，并继续原本的结算后流程。

### 5. 绑定阶段显示文本

在 UI 中准备两个 `TextMeshPro - Text`：

- 一个显示当前阶段数。
- 一个显示当前阶段目标金币。

选中挂有 `RanchUIController` 的对象，在 Inspector 中找到：

- `Stage Text`
- `Stage Goal Money Text`

分别把两个 TMP 文本拖进去。

脚本只会写数字，例如 `1` 和 `25`。如果想显示“当前阶段：1”或“目标：25”，可以在 UI 里用静态文字搭配这两个数字文本。

## 六、验证方法

### 验证 1：第 6 天才弹出面板

1. 打开游戏场景运行。
2. 阶段配置保持：6 天，25 金币。
3. 从第 1 天开始点击下一天结算。
4. 第 1 到第 5 天不应该弹出阶段结束面板。
5. 第 6 天结算完成后，阶段结束面板应该弹出。

### 验证 2：不管金币够不够都会弹出

测试不达标：

1. 把第 1 阶段目标金币设得很高，例如 `999`。
2. 运行到第 6 天结算完成。
3. 面板应该弹出。
4. 支付/继续按钮应该变成不可点击，玩家只能点击放弃按钮。

测试达标：

1. 把第 1 阶段目标金币设得很低，例如 `0`。
2. 运行到第 6 天结算完成。
3. 面板也应该弹出。
4. 支付/继续按钮应该可以点击。

### 验证 3：阶段文本正常显示

## 七、常见错误

### 错误 1：RanchTurnService 构造函数报错

如果报错说 `RanchTurnService` 构造函数参数不匹配，检查两个地方必须一起改：

- `RanchTurnService` 构造函数添加了 `RanchWinLoseController winLoseController` 参数。
- `RanchManager.CreateTurnService()` 创建 `new RanchTurnService(...)` 时也传入了 `winLoseController`。

### 错误 2：阶段结束后还能点下一天

检查 `RanchUIController` 中是否加了：

```csharp
manager.HasGameResult
```

也检查 `RanchManager.NextDay()` 开头是否有：

```csharp
if (HasGameResult)
{
    return;
}
```

### 错误 3：第 6 天不弹面板

检查：

- `RanchWinLoseController` 是否挂到场景中。
- `RanchManager.Initialize(...)` 中是否调用了 `ResolveWinLoseController()`。
- `RanchTurnService.CompleteAfterDailySettlement(...)` 中是否调用了 `TryResolveStageEnd(state.Day, state.Money)`。
- `Stage Goals[0].Duration Days` 是否为 `6`。

### 错误 4：支付按钮没反应

检查：

- 当前金币是否达到当前阶段目标；未达标时支付按钮会被禁用，这是正确表现。
- `Stage Goals` 是否至少有 2 个阶段。
- `Pay Button` 字段是否绑定了支付/继续按钮。
- 按钮是否绑定了 `OnPayButtonClicked()`。
- `RanchWinLoseController` 是否通过 `Initialize(this)` 拿到了 `RanchManager`。
