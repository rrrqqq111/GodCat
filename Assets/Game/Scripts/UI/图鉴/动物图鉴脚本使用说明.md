# 动物图鉴脚本使用说明

本文档记录 `Assets/Game/Scripts/UI/图鉴` 文件夹下动物图鉴相关脚本的用法，方便后续维护、扩展分类、接 UI 组件和排查问题。

## 脚本总览

当前图鉴系统主要由 3 个脚本组成：

| 脚本 | 作用 | 建议挂载位置 |
| --- | --- | --- |
| `AnimalBookCategoryToggleSelectionEffect` | 控制分类 Toggle 被选中时向右移动的视觉效果 | 分类 Toggle 的父物体，例如“动物家族标签组” |
| `AnimalBookIconListController` | 根据分类读取动物数据，生成 ScrollRect 中的动物图标，并处理图标点击 | 动物分类 Toggle 组或图标列表控制物体 |
| `AnimalBookSelectedAnimalPanel` | 接收被点击的动物数据，并刷新右侧/左侧详情 UI | 已制作好的动物信息 UI 面板 |

另外，`AnimalBookIconListController.cs` 中还包含两个辅助类型：

| 类型 | 作用 |
| --- | --- |
| `AnimalBookRarityColor` | 配置“稀有度 -> 颜色”的映射 |
| `AnimalBookRarityColorUtility` | 给指定 Image 应用稀有度颜色 |

## 一、标签选中右移效果

使用脚本：`AnimalBookCategoryToggleSelectionEffect`

### 挂载方式

1. 选中分类 Toggle 的父物体，例如“动物家族标签组”。
2. 添加组件 `AnimalBookCategoryToggleSelectionEffect`。
3. 这个父物体下的子物体应该是各个分类 Toggle，例如：
   - 所有动物
   - 有蹄动物
   - 鸟类动物
   - 食肉动物

### 字段说明

| 字段 | 说明 |
| --- | --- |
| 标签根节点 | 要收集 Toggle 的父节点。通常填当前物体，也可以为空，脚本会默认使用自身 Transform |
| 自动收集子标签 | 开启后会自动收集“标签根节点”下的所有 Toggle |
| 标签列表 | 手动指定 Toggle 列表。通常开启自动收集时不需要手填 |
| 选中右移距离 | Toggle 被选中后向右移动多少像素 |
| 移动动画时长 | 右移动画持续时间。填 0 会立即移动 |

### 注意事项

- Toggle 本身需要在同一个 `ToggleGroup` 里，保证一次只选中一个分类。
- 如果后续新增分类 Toggle，并且开启了“自动收集子标签”，一般不需要手动改这个脚本。
- 如果运行时动态增加 Toggle，可以调用 `Refresh()` 重新收集并刷新位置。

## 二、动物图标列表生成

使用脚本：`AnimalBookIconListController`

这个脚本负责：

- 从 `Assets/Game/Data/Animals` 读取所有 `AnimalData`
- 根据 Toggle 分类筛选动物
- 按稀有度排序动物
- 用图标模板生成 ScrollRect 列表
- 点击图标后刷新 `AnimalBookSelectedAnimalPanel`
- 根据稀有度给模板中的指定 Image 变色

### 挂载方式

建议挂在“动物家族标签组”或专门的列表控制物体上。

### 必填字段

| 字段 | 说明 |
| --- | --- |
| 动物数据根目录 | 动物数据根路径，默认 `Assets/Game/Data/Animals` |
| 滚动矩形 | 展示动物图标的 `ScrollRect` |
| 内容根节点 | ScrollRect 的 Content，一般是挂了 GridLayoutGroup / ContentSizeFitter 的对象 |
| 图标模板 | 单个动物图标模板。脚本会复制它生成列表 |
| 模板动物图标图像 | 模板里真正显示动物 Sprite 的 Image |
| 选中动物显示面板 | 点击动物图标后要刷新的详情组件 |
| 分类绑定列表 | Toggle 和动物家族的对应关系 |

### 其他字段

| 字段 | 说明 |
| --- | --- |
| 模板稀有度变色图像 | 模板中需要按稀有度变色的 Image。必须是图标模板本身或其子物体 |
| 稀有度颜色表 | 配置稀有度 0-4 对应颜色 |
| 默认稀有度颜色 | 找不到对应稀有度颜色时使用的颜色 |
| 隐藏模板 | 运行时是否隐藏原始模板。建议开启 |
| 编辑器自动读取动物数据 | 在 Editor 下自动从动物数据根目录刷新动物数据列表 |
| 动物数据列表 | 缓存的动物数据。运行时实际读取这个列表 |

### 分类绑定列表配置

每个元素代表一个分类 Toggle：

| 字段 | 说明 |
| --- | --- |
| 标签 | 对应的 Toggle |
| 动物家族 | 要筛选的 `AnimalData.Family` |
| 显示全部 | 开启后忽略动物家族，显示所有动物 |

推荐配置：

| Toggle | 动物家族 | 显示全部 |
| --- | --- | --- |
| 所有动物 | 空 | 开启 |
| 有蹄动物 | `Hoofed` | 关闭 |
| 鸟类动物 | `Bird` | 关闭 |
| 食肉动物 | `Carnivora` | 关闭 |

### 排序规则

当前动物列表排序规则为：

1. 稀有度 `Rarity`
2. 家族 `Family`
3. 显示名 `DisplayName`
4. ID `Id`

也就是说，“所有动物”页签下也会先按稀有度排列。

### 图标点击逻辑

生成图标时，脚本会自动确保图标物体上有 `Button` 组件。

点击图标后会调用：

```csharp
selectedAnimalPanel.Refresh(animalData);
```

因此，想让点击后详情 UI 正常刷新，必须把“选中动物显示面板”字段拖好。

## 三、选中动物信息面板

使用脚本：`AnimalBookSelectedAnimalPanel`

这个脚本只负责把传进来的 `AnimalData` 显示到你已经做好的 UI 组件上，不依赖旧的动物详情页。

### 挂载方式

挂在你制作好的动物信息面板根物体上。

### 字段说明

| 字段 | 对应数据 |
| --- | --- |
| 动物名称文本 | `AnimalData.DisplayName` |
| 家族图标图像 | `AnimalData.FamilyIcon` |
| 基础属性文本 | `AnimalData.BaseMoney` |
| 能力描述文本 | 优先显示 `Ability.Desc` 和子能力描述；没有能力时显示动物描述 |
| 动物图标图像 | `AnimalData.Icon` |
| 稀有度变色图像 | 详情面板中需要按稀有度变色的 Image |
| 稀有度颜色表 | 配置稀有度 0-4 对应颜色 |
| 默认稀有度颜色 | 找不到对应稀有度颜色时使用的颜色 |

### 能力描述显示规则

1. 如果动物有 `AbilityData`，优先显示 `Ability.Desc`。
2. 如果 `AbilityData.SubAbilities` 中也有描述，会追加到下一行。
3. 如果没有能力描述，则显示 `AnimalData.Description`。
4. 如果都没有，则显示“无能力”。

## 四、新增动物后的更新方式

新增动物时，需要创建新的 `AnimalData` 资源，并放到动物数据根目录下：

```text
Assets/Game/Data/Animals
```

可以放在已有家族文件夹中，例如：

```text
Assets/Game/Data/Animals/Hoofed
Assets/Game/Data/Animals/Bird
Assets/Game/Data/Animals/Carnivora
```

只要满足以下条件，图鉴就能自动读取：

- 资源类型是 `AnimalData`
- 放在 `动物数据根目录` 下或其子文件夹中
- `Family` 字段填写正确，例如 `Hoofed`、`Bird`、`Carnivora`
- `Icon` 字段有动物图标

在 Unity Editor 中，如果 `编辑器自动读取动物数据` 开启，脚本会在 Inspector 改动或资源刷新时尝试更新 `动物数据列表`。

如果发现新增动物没有出现，可以手动在组件右上角菜单中执行：

```text
Refresh Animal Catalog From Assets
```

## 五、新增动物分类的方式

假设要新增一个“水生动物”分类：

1. 在分类 Toggle 组下新增一个 Toggle。
2. 确认这个 Toggle 加入同一个 `ToggleGroup`。
3. 在 `AnimalBookIconListController` 的“分类绑定列表”中新增一个元素。
4. 把新 Toggle 拖到“标签”字段。
5. “动物家族”填写对应的 `AnimalData.Family`，例如 `Aquatic`。
6. “显示全部”保持关闭。
7. 新动物的 `Family` 也填写 `Aquatic`。

如果 `AnimalBookCategoryToggleSelectionEffect` 开启了“自动收集子标签”，新增 Toggle 后选中右移效果会自动包含这个新标签。

## 六、稀有度颜色配置

动物图标列表和详情面板都可以配置稀有度颜色。

### 图标列表变色

在 `AnimalBookIconListController` 中配置：

| 字段 | 说明 |
| --- | --- |
| 模板稀有度变色图像 | 从图标模板里拖入要变色的 Image |
| 稀有度颜色表 | 添加 0-4 稀有度颜色 |
| 默认稀有度颜色 | 缺省颜色 |

注意：`模板稀有度变色图像` 必须拖“图标模板自身或子物体上的 Image”。不要拖场景里已经生成出来的图标，也不要拖详情面板里的 Image。

### 详情面板变色

在 `AnimalBookSelectedAnimalPanel` 中配置：

| 字段 | 说明 |
| --- | --- |
| 稀有度变色图像 | 详情面板中需要变色的 Image |
| 稀有度颜色表 | 添加 0-4 稀有度颜色 |
| 默认稀有度颜色 | 缺省颜色 |

脚本会保留原 Image 的透明度，只修改 RGB 颜色。

## 七、常见问题

### 1. Inspector 字段没有显示中文

图鉴相关字段的中文显示来自两部分：

- 脚本字段上的 `InspectorName`
- `Assets/Game/Scripts/Editor/AnimalBookInspectorEditors.cs` 自定义 Inspector

如果没有显示中文：

1. 等待 Unity 编译完成。
2. 确认 `AnimalBookInspectorEditors.cs` 位于 `Editor` 文件夹下。
3. 重新选中挂有组件的物体。
4. 必要时右键脚本执行 Reimport。

### 2. 点击分类后没有生成动物图标

检查：

- `ScrollRect` 是否已拖入。
- `Content Root` 是否是 ScrollRect 的 Content。
- `Icon Template` 是否拖入。
- `Template Animal Icon Image` 是否是模板下显示动物图标的 Image。
- `Animal Catalog` 是否有数据。
- 分类绑定中的 `Family` 是否和 `AnimalData.Family` 完全对应。

### 3. 点击动物图标后详情不刷新

检查：

- `AnimalBookIconListController` 的“选中动物显示面板”是否已拖入。
- 详情物体上是否挂了 `AnimalBookSelectedAnimalPanel`。
- `AnimalBookSelectedAnimalPanel` 中各个 Text / Image 字段是否已绑定。

### 4. 新增动物没有自动出现

检查：

- 动物资源是否是 `AnimalData`。
- 是否放在 `Assets/Game/Data/Animals` 或其子文件夹。
- `编辑器自动读取动物数据` 是否开启。
- 手动执行 `Refresh Animal Catalog From Assets`。

### 5. 稀有度颜色不生效

检查：

- `Rarity Colors` 是否配置了对应稀有度。
- 颜色 Alpha 不要是 0。
- 图标列表中拖入的变色 Image 必须属于图标模板。
- 详情面板中拖入的变色 Image 必须属于详情面板。

## 八、当前不包含的功能

目前本文档对应的是动物图鉴系统。

道具、天赋、地形图鉴的通用读取控制器已撤销，当前没有保留相关脚本。如果后续要重新做，可以参考动物图鉴的结构重新扩展，但需要单独确认：

- 每类数据对应的 ScriptableObject 类型
- 数据文件夹路径
- 图标字段名称
- 详情面板字段
- 是否需要稀有度排序和颜色
